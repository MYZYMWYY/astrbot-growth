# 成长型自我 · AstrBot 插件

给 Bot 一份**会自己改写的自我描述**：每攒够 N 条对话，它读一遍最近聊的内容，把"我是谁"往前推一小步。

> 固定人设是"你写一段提示词，它照着演，一年后还是那段话"。
> 这个插件要的是"每次聊完，它自己变一点"。

## 核心设计

```
anchor.md   锁死：身份、底线、经历 —— 反思永远改不了
    +
self.md     可变：我怎么说话 / 我在意的人 / 我最近在想 / 我记得的事
    ↓
每 N 条对话反思一次 → 写新 self.md（旧版进 history，带 diff）
```

为什么分两层：**自我改写的提示词最容易越写越偏**。不锁死一部分，几轮之后它就认不出自己了。

## 它是怎么"成长"的

1. 收到私聊消息 → 记进 `journal/日期.md`，计数 +1
2. 每次回复前把 `self.md` 注入系统提示
3. 计数到阈值 → 后台反思（不阻塞回复）：
   - 输入：旧的可变部分 + 最近对话
   - 输出：新的可变部分（字数受限、改动比例受限）
   - 保存：`history/self_XXX.md` + `diff_XXX.md`
4. 每 N 天生成一份「我变了什么」报告

## 安装

放到 `AstrBot/data/plugins/astrbot_plugin_growth/`，重启 AstrBot。无额外依赖。

第一次运行时会在插件数据目录生成 `anchor.md`（锁定的自我）和 `self.md`（可变的自我）。

### 定制 anchor.md

`anchor.md` 是唯一需要你手写的东西，建议包含：

- 它是什么（不用装成真人）
- 底线（不泄密、不编造记忆）
- 你们一起经历过什么（这部分最有价值——它靠这个"记得"）

写完之后，反思只会改下面四块，碰不到这一段。

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | true | 总开关 |
| `scope_prefix` | 空 | 只在这个 UMO 前缀的会话生效 |
| `interval` | 40 | 多少条消息反思一次 |
| `max_self_chars` | 1500 | self.md 字数上限（每轮注入，直接算 token） |
| `style_change_limit` | 0.65 | 单次改写允许的最大变化比例 |
| `report_interval_days` | 14 | 变化报告间隔 |
| `provider_id` | 空 | 反思用哪个模型，空则用默认 |

## 指令

| 指令 | 作用 |
| --- | --- |
| `/growth` | 看版本、计数进度 |
| `/growth show` | 打印当前自我描述 |
| `/growth reflect` | 立刻强制反思一次 |
| `/growth reset` | 重置回初始状态（保留 anchor） |

## 踩坑

1. **锚定段一定要外置成文件**，别写死在代码里。否则你想改经历的时候得改代码、重启、还可能被插件更新覆盖。
2. **改动比例要设上限**。不设的话，两三次反思之后整份自我描述会被推倒重写，"成长"变成"随机漂移"。
3. **字数上限直接影响每轮 token**。1500 字约等于 1500 token，每一条消息都要付。想养得细，就得接受这个成本。
4. **反思要能失败**。模型输出不合格（超字数、结构错、瞎编）时必须重试或放弃，不能把烂内容写进 self.md。
